## 一、RPC 方法契约（前端 → Rust → Python，共 14 个）

Rust 命令层现为 snake_case（`portfolio.list` → `portfolio_list`），前端经 `LEGACY_MAP` 映射；**M1-R4 统一为点分式后删除映射层**。下表"Rust 命令"列为现状。

| # | 契约方法 | 请求 params | 响应 data | Rust 命令（现状） | 前端 api | 分层 |
|---|---|---|---|---|---|---|
| 1 | `portfolio.list` | `{}` | `Holding[]` | `portfolio_list` | `listHoldings()` | 核心 |
| 2 | `portfolio.add` | `{symbol*, name*, market?, asset_type?, quantity*, cost_price*, currency?}` | `Holding`（含 id） | `portfolio_add` | `addHolding()` | 核心 |
| 3 | `portfolio.remove` | `{id*}` | `{success, deleted_id}` | `portfolio_remove` | `removeHolding()` | 核心 |
| 4 | `quote.get` | `{symbol*, asset_type?}` | `QuoteData` | `quote_get` | `getQuote()` | 核心 |
| 5 | `quote.subscribe` | `{symbols: string[]}` | `{success, quotes: QuoteData[]}` | `quote_subscribe` | —（内部） | 核心 |
| 6 | `quote.refresh` | `{symbols: string[], force?: boolean}` | `QuoteData[]` | （M1-R2 新增 `quote_refresh`） | `refreshQuotes()` | 核心（手动刷新） |
| 7 | `skill.execute` | `{input: {message, …}, request_id}` | skill 执行结果 | `skill_execute` | `executeSkill()` | AI（M3） |
| 8 | `skill.cancel` | `{request_id}` | `{success, cancelled, request_id, reason?}` | `skill_cancel` | `cancelSkill()` | AI（M3） |
| 9 | `alert.list` | `{}` | `AlertRule[]` | `alert_list` | `listAlerts()` | 核心 |
| 10 | `alert.add` | `{portfolio_id*, threshold_percent?, direction?, cooldown_minutes?}` | `AlertRule` | `alert_add` | `addAlert()` | 核心 |
| 11 | `alert.remove` | `{id*}` | `{success, deleted_id}` | `alert_remove` | `removeAlert()` | 核心 |
| 12 | `alert.notify` | `{}` | `{success}` | `alert_notify` | —（测试用） | 内部 |
| 13 | `config.get` | `{}` | `Record<string, unknown>` | `config_get` | `getConfig()` | 核心 |
| 14 | `config.set` | `{key*, value*}` | `{success, key, value}` | `config_set` | `setConfig()` | 核心 |
| 15 | `stats.summary` | `{}` | `{total_cost, total_value, total_pnl, total_pnl_pct, mood, …}` | （Rust 未暴露，M2 按需） | — | 核心 |

*`*` 为必填；`?` 可选含默认值（market=cn / asset_type=stock / currency=CNY / threshold_percent=3.0 / direction=both / cooldown_minutes=5）*

**注**：`#6 quote.refresh` 为目标契约（M1-R2 实现时落地：Python 侧 `force=true` 绕过交易窗口并触发单次提醒评估；Rust 透传响应——修复 G2/G3）。当前前端误用 `quote.subscribe` 且不带 symbols，属已知缺陷，M1-R2 一并修复。

### 1.1 数据结构定义

```typescript
// Holding（对齐 Rust PortfolioItem / Python portfolio 表行 + 实时计算字段）
{ id: number; symbol: string; name: string; market: "cn"|"hk"|"us";
  asset_type: "stock"|"fund"; quantity: number; cost_price: number; currency: string;
  current_price: number; change_percent: number; pnl_amount: number; pnl_percent: number }

// AlertRule（对齐 alert_rules 表）
{ id: number; portfolio_id: number; symbol: string; name: string;
  threshold_percent: number; direction: "up"|"down"|"both";
  is_active: 0|1; cooldown_minutes: number }

// QuoteData（对齐 Python Quote.to_dict）
{ symbol: string; name: string; current_price: number; open_price: number;
  high_price: number; low_price: number; change_amount: number; change_percent: number;
  volume: number; turnover: number; currency: string }
```

## 二、事件契约（Python → Rust → 前端）

| 事件 | Python stdout 推送 | Rust 转发（emit） | 前端监听 | 载荷 |
|---|---|---|---|---|
| 提醒触发 | `alert.notify` | `alert_push`（数组，广播全部窗口） | `alert_push` | `{alerts: AlertEvent[]}` |
| 气泡定位 | —（Rust 计算） | `bubble:placement`（bubble 窗口） | `bubble:placement` | `{tail_offset, side: "above"\|"below"}` |
| AI 状态（M3 预留） | `ai.state` | `ai:state`（广播） | `ai:state` | `{status: "disabled"\|"checking"\|"installing"\|"pulling"\|"ready"\|"error", detail?}` |

```typescript
// AlertEvent（quote_service._event_to_dict 契约）
{ symbol: string; name: string; current_price: number;
  trigger_type: "sudden"|"up"|"down";   // sudden=3%骤变默认规则
  triggered_at: number;                  // unix 秒

```

## 四、防漂移机制（M1 落地）

1. **Python 启动自检**：main.py 启动时向 stderr 打印注册方法集（`rpc.methods`），与本文档 §一 diff
2. **冒烟基线**：`smoke_all.py` 覆盖全部 14 方法（§五），任何契约/后端改动必须先过冒烟
3. **前端类型同源**：`contracts.ts` 结构定义与本文档 §1.1 逐字段对齐，review 时对照
4. **LEGACY_MAP 生命周期**：M1-R4 Rust 命令改点分式 → 前端删映射层 → 冒烟回归

## 五、PRD v3.1 勘误记录（C1/C2/C3 裁定）

| # | PRD v3.1 原文 | 勘误为 | 依据 |
|---|---|---|---|
| C1 | `alert.add` params = `portfolio_id, up_percent, down_percent, enabled` | `portfolio_id, threshold_percent, direction, cooldown_minutes` | B3 已按单条单方向交付；多条规则可覆盖双阈值场景；enabled→is_active 由规则级字段承担 |
| C2 | `portfolio.remove` params = `symbol` | `id` | 唯一键，防同市场重复代码误删；Python 已实现级联删除 alert_rules |
