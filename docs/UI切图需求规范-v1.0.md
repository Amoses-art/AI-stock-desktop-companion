## 二、P0：桌宠皮肤状态图（核心）

### 2.1 目录与命名（必须严格遵守）

```
frontend-v3/public/skins/{皮肤名}/{状态名}.png
```

| 皮肤名（目录名） | 说明 |
|---|---|
| `tech-bull` | 机械金牛（主力皮肤，打样首选） |
| `pixiu` | 貔貅 |
| `hamster` | 仓鼠 |

### 2.2 状态清单与触发场景

| 状态文件名 | 触发条件 | 表情/姿态要求 |
|---|---|---|
| `idle.png` | 默认待机（盈亏 -1%~+1%） | 平静正视，无夸张表情 |
| `happy.png` | 持仓总盈利 > +1% | 开心/得意，可举金币、上涨箭头元素 |
| `sad.png` | 持仓总亏损 < -1% | 沮丧/低头，可配下跌箭头元素 |
| `alert.png` | 阈值提醒触发时 | 惊讶/警觉，可配感叹号元素 |
| `sleep.png` | 5 分钟无操作休眠 | 闭眼/打盹，可配 Zzz 元素 |
| `blink.png` | 待机随机眨眼（约 4s 一次，120ms） | 闭眼帧，姿态与 idle 一致仅眼睛闭合 |
| `drag.png`（新增） | 被用户拖拽移动中 | 挣扎/紧张/晕眩等趣味表情 |
| `press.png`（新增，可选） | 鼠标按住未松开 | 身体微压缩/期待表情；不提供则前端用 CSS scale 模拟 |

> 触发逻辑已在代码冻结（`moodFromPnl` / 状态机转换表），切图只需保证每状态表情可辨识——用户距离屏幕 50cm 时不用刻意分辨就能区分 6 个基础状态。

### 2.3 尺寸与格式

| 项 | 要求 |
|---|---|
| 画布尺寸 | **256 × 256 px**（等边，正方形画布，主体居中） |
| 主体占比 | 约 70%~85%，四周留呼吸空间（前端显示区约 110px，需覆盖 2x 屏） |
| 格式 | **PNG-24，透明底**（禁止白底/纯色底） |
| 对齐基准 | 同一皮肤所有状态图：**主体锚点严格对齐**（即逐帧切换时身体不跳动，只有表情/局部变化） |
| 色彩模式 | sRGB |
| 文件体积 | 单张 ≤ 150KB |

> 「锚点对齐」是硬要求：眨眼/情绪切换是同坐标叠加换图，若各状态主体位置偏移会出现"跳帧"。

## 三、P0：应用图标

### 3.1 主图标（应用/安装包/任务栏）

| 交付物 | 规格 | 用途 |
|---|---|---|
| `icon.ico` | 含 16/24/32/48/64/128/256 七档尺寸的多分辨率 ico | Windows 应用图标 |
| `icon.png` | 512 × 512，透明底 | 源图/关于页 |
| `128x128.png` | 128 × 128 | Tauri 打包要求 |
| `128x128@2x.png` | 256 × 256 | Tauri 打包要求 |
| `32x32.png` | 32 × 32 | Tauri 打包要求 |

> 设计元素建议：与主力皮肤（tech-bull）形象一致的牛头/吉祥物 + 涨跌元素；小尺寸（16px）下需仍可辨识，建议提供单独简化的 16px 版本而非直接缩放。

### 3.2 托盘图标

| 状态 | 文件名 | 规格 |
|---|---|---|
| 常规 | `tray.png` | 32 × 32 PNG，可带透明底 |
| 提醒态 | `tray-alert.png` | 32 × 32，右上角红色角标（与桌宠铃铛红点呼应） |

> 提醒态用于阈值触发后托盘图标变化，替代当前的红点数字方案（托盘图标不适合渲染文字数字）。

## 四、P1：帧动画（切图升级交互动画）

动画实现方式为 **sprite sheet 横向帧条**：一组动画切成长条 PNG，前端用 CSS `steps()` 逐帧播放。要求同一动画**所有帧等宽**、**主体锚点对齐**。

### 4.1 眨眼动画（替换现有双图切换）

| 项 | 要求 |
|---|---|
| 文件名 | `anim-blink.png` |
| 帧数 | 4~6 帧（闭→半闭→全闭→半闭→睁开） |
| 单帧尺寸 | 256 × 256（与状态图一致） |
| 总尺寸 | 如 6 帧 = 1536 × 256 |
| 帧率 | 100~120 ms/帧 |

### 4.2 提醒触发动画（alert 状态强化）

| 项 | 要求 |
|---|---|
| 文件名 | `anim-alert.png` |
| 帧数 | 6~8 帧（弹跳/挥手/感叹号闪烁循环） |
| 单帧尺寸 | 256 × 256 |
| 帧率 | 120 ms/帧，循环播放直到气泡关闭 |

### 4.3 入场动画（应用启动，可选）

| 项 | 要求 |
|---|---|
| 文件名 | `anim-enter.png` |
| 帧数 | 6~10 帧（从屏幕边缘探头/伸展起身） |
| 帧率 | 100 ms/帧，播放一次后进入 idle |

> 呼吸浮动（待机上下 4px）由 CSS transform 实现，**无需切图**，请勿为此出素材。

## 七、交付规范汇总

1. **格式**：全部 PNG-24 透明底（ico 除外）；动画用 sprite sheet 横帧条，不接受 GIF/APNG/WebP
2. **命名**：全小写 + 连字符，与本文档文件名完全一致
3. **放置**：按第 2.1 节目录结构，交付时可直接打包为 `skins.zip`（内含皮肤名文件夹），前端解压即用
4. **对齐**：同皮肤所有状态图、同动画所有帧，主体锚点严格居中对齐
5. **校验**：每张图请在深色背景（#0d1117）与浅色背景各预览一次，确保透明边缘无白边/黑边
6. **交付目录**：`D:\BaiduNetdiskDownload\traework\frontend-v3\public\skins\`（皮肤）与 `...\src-tauri\icons\`（应用图标）
