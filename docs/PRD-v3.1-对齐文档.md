## 一、产品分层修订（核心决策）

### 1.1 分层定义

| <br /> | 核心层（默认安装即用）                                                                     | AI 层（可选启用）                             |
| ------ | ------------------------------------------------------------------------------- | -------------------------------------- |
| 能力     | 桌宠交互（情绪/皮肤/拖拽/托盘/休眠）、持仓管理（三市场/个股基金双标签）、阈值提醒（预制 3% 骤变 + 自定义阈值）、实时行情（多源链路 + 调度策略） | 聊天对话、9 意图 Skill 路由、深度研究 Skill、NLU 模型兜底 |
| 外部依赖   | 无                                                                               | Ollama + qwen2.5（开发者验证 7b，分发默认 3b）     |
| 里程碑    | **M1 核心版可分享**                                                                   | **M2 完整版**                             |

原 PRD 中"自然语言对话"等对话类 P0 项整体移入 AI 层；核心层验收以"持仓管理闭环"为最高优先级。

### 1.2 AI 能力开关（双入口，统一链路）

* **首启选择向导（方案 B，已确认）**：安装包统一，首次启动弹轻量选择卡片——"仅使用持仓管理 / 开启 AI 对话（需下载约 2GB 本地模型）"。

* **设置端开关**：随时开启/关闭。开启走统一引导链路：检测 Ollama → 静默安装（`OllamaSetup.exe /S`）→ ModelScope 国内镜像配置 → 后台拉取 qwen2.5:3b → 进度事件驱动 UI → 完成置 ready。

* **关闭行为**：只隐藏 AI 入口，不卸载模型（避免反复下载）。

* **AI 关闭时的对话气泡（已确认）**：完全隐藏，仅保留桌宠 + 持仓面板。

### 1.3 Feature Flag 状态机

存储于 `user_config` 表：

* `ai_enabled`: bool

* `ai_status`: `disabled` → `installing` → `ready` | `failed`（failed 可重试回到 installing）

传播路径：Python flag 服务 → Rust（`ai:state` 事件）→ 前端（创建/隐藏对话窗口与相关设置项）。

## 二、行情刷新调度策略（替代原"交易时段拦截"）

> 原需求 4.3.2/交易时段拦截的出发点修正：**保证交易时段内秒级自主刷新持仓数据，非交易时段不主动请求**。它是"调度策略"，不是"拦截"。

### 2.1 交易窗口定义

| 市场    | 刷新窗口              | 说明                                                                 |
| ----- | ----------------- | ------------------------------------------------------------------ |
| A股    | 工作日 09:15 – 15:00 | 09:15 含集合竞价；午休 11:30 – 13:00 默认降频（见 2.2）；节假日以 chinese\_calendar 判定 |
| 港股/美股 | M1 简化为常开 + 限频     | 完整市场时段日历列入后续迭代                                                     |

窗口边界可配置（`user_config`：`poll_window_start` / `poll_window_end` / `poll_lunch_break`）。

### 2.2 轮询行为

* **交易时段内**：秒级轮询，默认 10 秒（可配置 5–30 秒），批量拉取全部持仓（腾讯批量接口一次请求）。

* **午休降频**：11:30 – 13:00 默认降至 120 秒（数据静止，保留心跳与连接健康探测）。

* **非交易时段**：完全停止主动请求。持仓面板显示最后快照 + 时间戳 + "已收盘"状态标记。

* **提醒引擎联动**：轮询暂停时阈值评估同步暂停；手动刷新触发单次评估。

### 2.3 手动刷新（新增前端交互）

* 持仓面板增加"刷新 icon"。

* 点击 → 一次性 `quote.refresh` 请求（**绕过交易窗口判断**，用户显式要求的取数优先）。

* 请求期间 icon 转圈；返回后更新快照时间戳；受数据源限频保护（熔断器仍然生效）。

## 三、K线趋势图（可选优化 · 决策记录）

**决策：M1 不做，列入 M2 后持仓项"展开详情"增强。**

方案（分时图优先）：

1. **数据采集**：交易时段轮询的快照自采集为分钟序列（内存 + SQLite 当日表），零额外接口成本。
2. **缺口回补**：应用在盘中启动时，首次通过腾讯分钟线 API 回补当日 0 → 当前时刻的分时数据。
3. **渲染**：TradingView lightweight-charts（\~45KB，金融图表库），持仓项展开详情内嵌当日分时图。
4. **日 K 线**：次级增强，腾讯/AKShare 历史日线，默认展示最近 60 根。

## 四、IPC 契约冻结表

### 4.1 Invoke 命令（前端 → Rust → Python）

| 命令                          | 参数                                                 | 返回                        | 层             |
| --------------------------- | -------------------------------------------------- | ------------------------- | ------------- |
| `portfolio.list`            | —                                                  | holdings\[]               | 核心            |
| `portfolio.add`             | symbol, name, cost, quantity, market, asset\_type  | holding                   | 核心            |
| `portfolio.remove`          | id                                                | ok                        | 核心            |
| `quote.get`                 | symbol                                             | QuoteData                 | 核心            |
| `quote.refresh`             | symbols, force                                            | QuoteData\[]              | 核心（手动刷新，绕过窗口） |
| `alert.list`                | —                                                  | rules\[]                  | 核心            |
| `alert.add`                 | portfolio\_id, threshold\_percent, direction, cooldown\_minutes | rule                      | 核心            |
| `alert.remove`              | id                                                 | ok                        | 核心            |
| `config.get` / `config.set` | key\[, value]                                      | value / ok                | 核心            |
| `ai.get_state`              | —                                                  | {ai\_enabled, ai\_status} | 核心（读）         |
| `ai.enable`                 | —                                                  | ok（触发引导链路）                | AI            |
| `ai.disable`                | —                                                  | ok                        | AI            |
| `skill.execute`             | input{message, request\_id}                        | SkillOutput               | AI            |
| `skill.cancel`              | request\_id                                        | ok                        | AI            |
| `window.set_mode`           | pet / panel / chat                                 | ok                        | 核心            |
| `window.set_position`       | x, y                                               | ok                        | 核心            |
| `window.edge_snap`          | —                                                  | ok                        | 核心            |

### 4.2 事件（Python → Rust → 前端）

| 事件                | 载荷                        | 层         |
| ----------------- | ------------------------- | --------- |
| `quote:tick`      | QuoteData\[]              | 核心        |
| `quote:alert`     | AlertEvent\[]             | 核心        |
| `pet:state`       | state                     | 核心        |
